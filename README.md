# ಶಿಕ್ಷಣ ಇಲಾಖೆ ನೌಕರರ ಸಹಕಾರ ಸಂಘ
# ಚಿಕ್ಕನಾಯಕನಹಳ್ಳಿ, ತುಮಕೂರು ಜಿಲ್ಲೆ

ಶಿಕ್ಷಣ ಇಲಾಖೆಯ ನೌಕರರ ಆರ್ಥಿಕ ಮತ್ತು ಸಾಮಾಜಿಕ ಅಭಿವೃದ್ಧಿಗಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿರುವ ಸಹಕಾರ ಸಂಘ.

### ನಮ್ಮ ಸಂಘದ ಉದ್ದೇಶಗಳು
- ಸದಸ್ಯರಿಗೆ ಆರ್ಥಿಕ ನೆರವು ನೀಡುವುದು.
- ಕಡಿಮೆ ಬಡ್ಡಿದರದಲ್ಲಿ ಸಾಲ ಸೌಲಭ್ಯ ಒದಗಿಸುವುದು.
- ಸದಸ್ಯರಲ್ಲಿ ಉಳಿತಾಯ ಮನೋಭಾವ ಬೆಳೆಸುವುದು.
- ಸದಸ್ಯರ ಕಲ್ಯಾಣ ಕಾರ್ಯಕ್ರಮಗಳನ್ನು ಆಯೋಜಿಸುವುದು.
- ಶಿಕ್ಷಣ ಮತ್ತು ಸಾಮಾಜಿಕ ಸೇವಾ ಚಟುವಟಿಕೆಗಳನ್ನು ಪ್ರೋತ್ಸಾಹಿಸುವುದು.

### ನಮ್ಮ ಸೇವೆಗಳು
1. ವೇತನ ಸಾಲ
2. ಆಧಾರ ಸಾಲ
3. ಠೇವಣಿ ಸೌಲಭ್ಯ
4. ಸದಸ್ಯರ ಕಲ್ಯಾಣ ಕಾರ್ಯಕ್ರಮಗಳು
5. ಪ್ರತಿಭಾ ಪುರಸ್ಕಾರ
